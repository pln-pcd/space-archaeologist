# Project description

For the project page field "High-Level Project Summary" (and the local form). 248 words (limit 250). No dashes.

Space Archaeologist is a free 3D browser game that turns the machines NASA left on the Moon and Mars into an adventure for kids aged 7 to 12. It answers "Abandoned but not Forgotten": these machines carry true stories, but kids mostly meet them in dense websites and textbooks.

Kids design an explorer and pick a mission. Mission 1 opens with real Apollo 11 film from NASA and a launch. On the Moon, kids brush dust off four real artifacts (Eagle's descent stage, the laser reflector, the seismometer and the plaque), tap clue stars, run hands-on activities, pin evidence, fill the Rock Box, rebuild the lander and file a report nobody can fail. Mission 2 keeps the Opportunity rover going on Mars.

Three design choices come from how kids learn. Nova, an AI guide, answers questions by voice or text, stays on space topics and uses sourced facts, so curiosity is rewarded safely. Star Gloves let kids scan, grab and send a laser ping with their real hands, so learning is active; mouse, keyboard and touch work too. Every story is read aloud with captions, so early readers can follow.

Every one of the game's 275 facts links to one of 46 NASA sources, checked by our fact tests. NASA footage and photos are credited, and Nova can read live NASA feeds. No accounts, camera and speech processed on the computer, an AI off switch for grown-ups and an offline mode make it safe and practical for classrooms.
